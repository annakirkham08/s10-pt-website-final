# Repository Name:  s10_pt_website_final   
This repository is for students to demonstrate their Git and GitHub skills.<br><br><br><br><br>  

## Project Descripton:

This project is a four-page website for **Pacific Trails Resort**, a fictional resort. The site includes a Home page, an Activities page, a Reservations page, and a Yurt Accommodations page.

Each content page was built on its own feature branch by a collaborator. I forked and cloned the repository, reviewed each branch, merged them into `main`, resolved merge conflicts, and tested navigation, layout, and images across all four pages.<br><br><br><br><br>

---

## Pages
- Home (`index.html`)
- Activities (`activities.html`)
- Reservations (`reservations.html`)
- Yurts (`yurts.html`)
